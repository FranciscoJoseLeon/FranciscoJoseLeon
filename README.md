<h2 align="center">🏠 Jeedom Home Automation Plugins (Open Source · 🇫🇷 🇬🇧 🇪🇸)</h2>

<p align="center">

</p>

### 📟 [plugin-awtrixng](https://github.com/FranciscoJoseLeon/plugin-awtrixng) — Awtrix NG & Light Matrix LED
Native Jeedom v4.2+ integration for **Awtrix NG** and **Awtrix Light** smart LED pixel matrix displays (**Ulanzi TC001**, **Ulanzi TC002**, and DIY **ESP32 / ESP32-S3 WS2812B** panels).

- **⚡ 100% Native HTTP REST API**: Direct, low-latency communication with your clocks (`/api/v1/notifications`) with **no MQTT broker or external daemon required**.
- **🔍 Auto Hardware & Sensor Detection**: Automatically detects screen resolution (`32×8`, `52×16`, or DIY `32×8` to `128×8`), hardware model, firmware version, and physical sensors (Battery, LDR Lux, Temperature, Humidity, Audio/TTS).
- **🖥️ Pixel-Perfect Live Simulator & Dashboard Widget**: Dedicated visual widget per device + real-time screen preview (`/api/v1/display/screen`).
- **🎨 Visual Pickers & 1-Click Commands**: Icon, color, and sound dropdowns, zero-JSON scenario syntax (`icon | #color | duration`), persistent carousel builder, multi-panel sync, and full JSON backup/restore.

---

### 🔊 [plugin-alexa_devices](https://github.com/FranciscoJoseLeon/plugin-alexa_devices) — Amazon Echo & Alexa Devices
Native Jeedom v4.2+ integration for **Amazon Echo and Alexa** hardware powered by the modern asynchronous Python library [`aioamazondevices`](https://github.com/chemelli74/aioamazondevices) and **Amazon AVS HTTP/2 real-time push**.

- **📡 Real-Time HTTP/2 Push**: Persistent event stream updating volume, playback state, Do Not Disturb (DND), and sensors instantaneously without aggressive polling.
- **🗣️ Full Voice & Media Control**: Text-to-Speech (`speak` with SSML), Whisper, Announcements, Voice Text Commands (`text_command`), Play/Pause/Stop/Next/Previous, Music/Radio, and built-in Sound Effects.
- **🌡️ Multi-Device & Sensor Support**: Supports Echo speakers & displays, Fire TV/Tablet, multiroom groups, and **Amazon Smart Air Quality Monitor** / Echo environmental sensors (Temperature, Humidity, PM2.5, VOC, CO, Illuminance, Presence).
- **🔐 Secure 2FA / OTP Login**: Interactive authentication flow with encrypted local session persistence and automated routine synchronization.
